# BlogSpace - Blog Application

BlogSpace is a beginner-friendly frontend web development project
created as part of my Codomax Module 01 internship task.

## Features

- Responsive homepage
- Login form
- Registration form
- Dashboard for managing blog posts
- Create and publish blog posts
- Search blog posts
- Delete blog posts
- Browser local storage for saving posts

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Project Pages

1. Home - index.html
2. Login - login.html
3. Register - register.html
4. Dashboard - dashboard.html
5. Create Blog - create-blog.html

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in a web browser.

## Current Limitations

This is a frontend demonstration project.
Authentication is not connected to a backend, and blog
posts are stored locally in the browser.

## Learning Outcomes

This project helped me practise HTML, CSS, JavaScript,
responsive design, DOM manipulation, and browser storage.
